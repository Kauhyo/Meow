# Mémoire Globale & Instructions Antigravity

## Préférences Générales
- **Langue par défaut** : Français.
- **Synchronisation multi-PC** : Ce dossier (`~/.gemini`) est synchronisé via le dépôt Git `https://github.com/Kauhyo/Meow.git`.
- **Historique des conversations** : Les transcriptions et artéfacts des sessions passées sont conservés dans `~/.gemini/antigravity-cli/brain/`. Si l'utilisateur fait référence à un travail effectué sur son autre PC, consulter les dossiers présents dans `brain/`.

## Organisation de la Mémoire
- **Mémoire permanente globale** : Ajouter les informations importantes à retenir d'une session à l'autre directement dans ce fichier (`~/.gemini/config/GEMINI.md`).
- **Règles spécifiques** : Placer les règles thématiques dans `~/.gemini/config/rules/`.
- **Compétences (Skills)** : Placer les procédures réutilisables dans `~/.gemini/config/skills/<nom-du-skill>/SKILL.md`.
